# Литературные заметки (фаза 0, 2026-09-30)

Прочитаны полностью: Bahramian et al., Chatzikyriakidis-Luo 2015, Luo-Soloviev-Xue 2013, Asher-Luo SuB17, DHoTT, TTS. По ключевым разделам: ConMeC, McGregor et al. 2017. Сайт Royal Holloway с рабочей машины был недоступен; тексты получены с зеркал (HAL, ACL Anthology, dagstuhl, arXiv, Konstanz OJS).

## Ключевые работы

| Работа | Что делает | Вывод для проекта |
|---|---|---|
| Bahramian, Nematollahi, Sabry, *Copredication in HoTT* (Indiana; формализовано в Agda) | Существительное как отождествление аспектов (пути в универсуме); счёт через "b qua physical". Метонимия («metaphor» в их терминах) вынесена из области | Ближайший предшественник; метонимия и коэрции не затронуты. Критика аксиомы инъективности верна |
| Luo-Soloviev-Xue, *Coercive subtyping: theory and implementation* (Inf. & Comp. 2013) | Когерентность: `c = c'` для коэрций между теми же типами; определима только в подсистеме без коэрционного определения (иначе любые две коэрции равны); в Plastic проверяется сравнением термов, для параметризованных неразрешима | Когерентность в MTT внешняя; при явных коэрциях становится внутренней |
| Chatzikyriakidis-Luo, *Individuation Criteria, Dot-types and Copredication* (MoL 2015) | Dot-типы, счёт, Coq; сноска 9: из `x =_X y` не следует `x =_Y y` без инъективности; вводится аксиома `¬(x=y:Book) → ¬(x=y:Phy)` (локально). Случай newspaper: линейные dot-типы и локальные коэрции, формально не разработаны | Основа C2; открытая проблема newspaper |
| Asher-Luo, *Formalization of Coercions in Lexical Semantics* (SuB17) | Зависимые коэрции `Book <c(h) Evt(h)` с определением по случаям (write/read); локальные коэрции (scope вручную); «hide» против «spell out» для доступности референта; многоаргументная зависимость | Зависимость от контекста в MTT уже есть; выбор чтения остаётся метауровнем. Наш вклад: выбор как элемент типа внутри теории |
| Poernomo, DHoTT (arXiv 2506.09671) | HoTT над эмбеддингами LLM; carry/rupture, дрейф значения | Близка архитектурой, не лексическими коэрциями; цитировать и развести |
| Poernomo, TTS (arXiv 2606.12504) | Смысл как наполнение рога, развилки, аппартность; омонимия разобрана, систематическая полисемия отложена | Словарь пересекается; различимость читаний (T18) родственна аппартности |
| ConMeC (Ghosh, Jiang 2025) | 6000 предложений, нарицательные, 6 категорий, бинарная разметка; BERT и LLM | Основной набор |
| McGregor et al. 2017 | Геометрическое обнаружение коэрции (SemEval-2010 T7) | Связанная постановка, дистрибутивная |

## Установленные факты

- Метонимия в MTT/HoTT-литературе формально практически не рассмотрена; прямого предшественника (HoTT + коэрции/метонимия + GF) в найденном нет. Поиск был не исчерпывающим.
- Конечные модели (`experiments/toy/`): (a) аксиома индивидуации Chatzikyriakidis-Luo нарушается в сценарии «три тома, два произведения»; (b) уровень 0 (обоснования) без усечения завышает число чтений и счёт; (c) на уровне группоидов различий предсказаний не найдено; число допустимых 2-клеток равно числу симметрий и наблюдаемо невидимо.
