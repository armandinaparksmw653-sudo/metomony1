# План V3 (2026-10-04): слои зависимых типов над референтами, бенчмарк WiMCor

Заменяет PLAN-V2 в части бенчмарка и порядка работ. Тейк и положение относительно литературы: notes/POSITIONING.md.

## 1. Тезис

Теория систем коэрсий **без требования когерентности**: гом-множества слоя расслоения не обязаны быть синглтонами, пространство прочтений слова есть фактор-множество
маршрутов по эквивалентностям, различимое вычислимо со свидетельствами; режимы Resolve, Retain, Conjoin, Family определены расслоением; сертификат выбранного прочтения
проверен в Agda относительно снимка базы знаний. Уровень множеств, не HoTT. Приложение: интерпретация метонимии как привязка сущности на WiMCor.

Чего не утверждаем: необходимость гомотопий; новизну идеи «прочтения из базы знаний» (Nastase, Strube); новизну копредикации через отождествление аспектов (Bahramian и др.)
и подсчёта через сетоиды (Chatzikyriakidis, Luo); прирост точности от формального слоя.

## 2. Схема

```
предложение, упоминание (слово, место p : Place)
  -> [данные] рамка предиката перед упоминанием (двухсловная; позже по зависимостному разбору)
  -> [таблица] веса сортов S по рамке (статистика train; Qwen как резерв для редких рамок): мягкий априор
  -> [формально] слой  Reading p = Σ s : Sort. Σ y : El(s). Compat(p, y)  (буквальное прочтение входит как s = Place, y = p)
  -> [нейронка] выбор элемента слоя по всему предложению (двухступенчатый: дешёвое ранжирование, затем LLM на лучших)
  -> [формально] сертификат: элемент лежит в слое; проверка в Agda относительно снимка
```

Слой не зависит от решения нейронки о сорте: сорт даёт только вес. Это делает формальный объект чистым, а ошибки типизации по рамке (около 14%) не фатальными.

## 3. Кто что делает (граница доверия)

| Компонент | Тип | Статус доверия |
|---|---|---|
| Определения: `Reading`, маршруты, фактор по эквивалентностям, режимы | формально, Agda | доказано/проверено |
| Проверка сертификата (элемент в слое, условия совместимости) | формально, Agda | проверено относительно снимка |
| Построение множеств `El(s)` и отношения `Compat` из Википедии и Викидаты | детерминированный код Python | воспроизводимо, не верифицировано |
| Привязка места к странице | оракул из разметки корпуса | оговорка: привязка не оценивается |
| Определение сортов и отношения совместимости | по определению самого корпуса (см. 4) | документировано |
| Веса сортов по рамке | статистика train, Qwen для редких рамок | не строго, потолок 0.86 |
| Выбор элемента слоя | нейронный (Qwen и лёгкий ранжировщик) | не строго, это измеряемая часть |

Агда гарантирует корректность относительно снимка (выбранный референт принадлежит слою, построенному из этого снимка). Полнота слоя и верность снимка не гарантируются: это
явная граница доверенной базы.

## 4. Слой кандидатов по определению корпуса (следующий шаг)

Авторы WiMCor собирали пары (место, референт) так (harvest/gen_metpairs.py): оба упомянуты на одной странице неоднозначности Википедии («Warwick (disambiguation)»),
**ссылаются друг на друга** по гиперссылкам, типы определены классами DBpedia/YAGO: место `PopulatedPlace`; институты `EducationalInstitution`; артефакты `Artifact`, `Product`,
`Creation`, `Structure`, `Building`; организации и команды `Company`, `Association`; события `Scandal`, `Event`. Мы определяем `Compat(p, y)` и сорта этим же способом.
Преимущества: детерминированно, документировано, строже (на странице неоднозначности около десятка записей). Оговорка: покрытие золотого референта почти 100% по построению (так корпус
собирался), поэтому это определение слоя, а не измерение базы знаний. Нужно проверить список классов по данным (в комментарии кода), размеры слоя и расхождение с текущим слоем
(поиск по имени и расположению; покрытие 94–100% для трёх типов, 58% для артефактов).

## 6. Метрики и базовые линии

- Привязка сущности: точность референта в целом и по типам; точность в режимах «неизвестное слово» и «неизвестный референт».
- Базовые линии: самый частый референт слова (лексический ярлык, на test все слова видены в train, точность типа по слову 0.82); выбор по рамке; нейронный выбор без слоя
  (открытый ответ); статистическое ранжирование по признакам имени и связей.
- Доля сертифицированных ответов и доля отсеянных неверных; прирост точности от формального слоя ожидаем малым, это надо писать честно.
- Собственные неоднозначные предложения (Fleet Street): несколько десятков для иллюстрации, не как бенчмарк.

## 7. Риски

- Артефакты: слой не охватывает разнородный тип (покрытие 58% в текущей версии); определение по корпусу должно помочь.
- Потолок рамок 0.86, артефакты и события почти не различаются локальной рамкой.
- Лексические ярлыки в WiMCor: простая запоминалка слова даёт высокую точность; без режимов обобщения результат бессмысленен.
- Размер снимка WiMCor в Agda: десятки тысяч элементов, возможны снимки по предложению или по месту.
- Литература: возможна работа с формальным определением несогласованных коэрсий, не найденная нами; чтение оставшихся источников.
