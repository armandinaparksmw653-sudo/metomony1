# Прогон ConMeC на Qwen2.5-7B-Instruct (Colab или Kaggle)

Задача: для каждого из 6000 предложений ConMeC получить оценку «метонимично/буквально» от модели, не
генерируя текст. Модель отвечает одним токеном (Yes/No или A/B), и мы сохраняем логарифмы вероятностей двух
ответов. Из них получается непрерывная оценка для кривых и порогов.

## Что запускается

Четыре семейства промптов на каждое предложение (всего 24 000 прогонов, около 150 токенов каждый):

| Код | Что спрашивает |
|---|---|
| `P0` | Использовано ли слово метонимично? (без указания типа) |
| `P1` | То же, но с типом метонимии из разметки ConMeC (как в статье ConMeC, где промпты зависят от категории) |
| `S1a`, `S1b` | Выбор между буквальным и метонимическим чтением типа; два порядка вариантов, чтобы убрать смещение по позиции |

Данные не копируются в репозиторий: скрипт скачивает `DATASET.csv` из исходного репозитория ConMeC (лицензия
Apache-2.0). Разбиение по документам: `dev` (около 1000 предложений) нужен для порога и примеров, `test`
(около 5000) не используется ни для чего, кроме оценки.

## Шаги в Colab

1. Откройте `experiments/llm/colab_score.ipynb` в Colab (Файл → Открыть блокнот → GitHub → вставьте адрес
   репозитория `armandinaparksmw653-sudo/metomony1`) или загрузите файл вручную.
2. Среда выполнения → Сменить тип среды → **T4 GPU**.
3. Выполните ячейки по порядку. Сначала **быстрая проверка** на 200 предложениях (несколько минут), потом
   полный прогон. Если сессия отключилась, запустите ту же ячейку снова: скрипт продолжит с места остановки.
4. Скачайте `out_qwen25_7b.jsonl` (около 2–3 МБ) и пришлите его сюда или загрузите в репозиторий через
   веб-интерфейс GitHub в папку `results/`.

Kaggle: те же команды, включите GPU и доступ в интернет в настройках блокнота.

## Ориентиры по времени и памяти (оценки, не измерения)

- Модель в 4-битном виде занимает около 5–6 ГБ видеопамяти; T4 (15 ГБ) хватает с запасом.
- Весь прогон: порядка 20–60 минут. Если видеопамяти не хватает, скрипт сам уменьшит размер пакета.

## Что я сделаю с файлом

`python experiments/llm/analyze.py out_qwen25_7b.jsonl` выдаёт на test: accuracy, macro-F1, F1 по метонимичному
классу, AUROC, доверительные интервалы бутстрапом и разбивку по шести типам. Режимы: **R0** (порог 0, ничего не
подбирается) и **R0t** (порог выбран на dev). Это базовая линия для варианта 1 и источник оценок скорера
для пайплайна.

## Проверено до вас

Разбиение, формат промптов и анализатор проверены на этой машине; сам скрипт проверен на крошечной случайной
модели той же архитектуры (логика пакетов, шаблон чата, возобновление), а токенайзер настоящей модели проверен
отдельно: ответы `Yes/No/A/B` однотокенные. На реальной модели и GPU скрипт ещё не запускался: поэтому первый
шаг, быстрая проверка, обязателен.
