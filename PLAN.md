# Metonymy as coercion routes: verified interpretation in GF + Cubical Agda

Рабочий план проекта (зафиксирован 2026-09-30). Язык данных: английский. Язык общения: русский.

## 1. Принятые решения

| Вопрос | Решение |
|---|---|
| Приоритет | Формальная сторона; точность на бенчмарках — сигнал корректности, не рекорд |
| Архитектура | **Вариант 2**: нейро-разбор окна «предикат + аргумент», символическое ядро (Haskell) строит и проверяет пути; Agda проверяет сертификаты. Вариант 1 («нейро предлагает, логика проверяет») строится первым как абляция A |
| Формальный тезис | Явные коэрции; `Coe(A,B) = Route/≈` (множества, параметр h-уровня сохраняется); значение предложения — семейство над `Coe` с режимами Resolve / Retain-∃ / Conjoin-∀ / семейство; счёт в образе коэрции; инвариантность относительно перекодирования онтологии |
| Высшие гомотопии | **Не тезис.** Фактов нет: кратность 2-клеток равна числу симметрий структуры и наблюдаемо невидима (`experiments/toy/two_cells.py`). Остаётся как обобщение (h-полиморфная теория) и побочный эксперимент (вариант C) |
| Проверка | Haskell выдаёт сертификаты, Agda их проверяет: `check c ≡ true → Valid c` |
| Новизна | Сочетание: проверяемая теория коэрций и метонимии + работающая система на бенчмарках. Главные теоретические вклады: T6, T9', T10-T12, T15 |

## 2. Формальный трек

Сложность: Л лёгкая, С средняя, Т трудная.

### Структура ядра
- **Лексикон** (единый источник истины; из него генерируются Haskell- и Agda-представления): типы `Ty`; рёбра-коэрции `Edge A B` с ID, условием включения контекстом и видом (функциональная или реляционная); 2-клетки (объявленные эквивалентности маршрутов); факты KB (снимок) с ID происхождения.
- **Маршруты** `Route A B`; `Coe A B := Route A B / ≈` (множественный фактор).
- **Семантика:** модель `M` (носители-множества, отношения для рёбер, предикаты). Значение предложения: Resolve `P(y)`; Retain `‖Σ y. R x y × P y‖`; Conjoin `(P1(c1 x), P2(c2 x))`; при неоднозначности значение — семейство `Interp : Coe A B → hProp`.
- **Два слоя:** синтаксический (термы, типизация, `check`; обычная Agda, `--safe`, компилируемая в Haskell) и семантический (кубическая Agda, теоремы). Совместимость флагов (`--cubical-compatible`) и компиляцию проверить до начала; запасной вариант — пакетная проверка через `refl` внутри Agda.
- Без `postulate`; версии Agda и библиотеки cubical зафиксированы.

### Теоремы

| № | Утверждение | Сл. |
|---|---|---|
| T1 | Типизация с явными коэрциями разрешима (проверяющий корректен и полон) | Л |
| T2 | Консервативность: коэрции стираются | Л |
| T3 | Корректность элаборации: `elab t = t'` ⇒ `t'` типизируем и `erase t' = t` | С |
| T4 | Полнота относительно неявных коэрций (Luo) для фрагмента (стретч) | Т |
| T5 | `Coe A B` — множество; маршруты образуют категорию | Л |
| T6 | **Независимость от маршрута:** если 2-клетки семантически корректны в `M`, то `r ≈ r' ⇒ ⟦r⟧ = ⟦r'⟧`; интерпретация — функтор `Coe → Rel` | С |
| T7 | Классификация `isContr`/`isProp`/число чтений; разрешимость ≈ и нормальные формы при ориентированной, конфлюэнтной, терминирующей системе 2-клеток | С-Т |
| T7' | Перечисление классов полно относительно лексикона и границы длины `k` | С |
| T8 | Подлексиконы: контекст задаёт подлексикон; отображение читаний только при условии на 2-клетки (блокирующие слова нарушают монотонность) — **переписать** | С |
| T9' | Решётка режимов: `∀ ⇒ Interp(k) ⇒ ∃`; Retain инвариантно по маршруту | Л-С |
| T10 | Необратимость Retain: нет сечения `‖Fib‖ → Fib` при слое мощности ≥ 2 | С |
| T11 | Условие Conjoin: допустим ⇔ есть общий источник; для омонимов (сумма типов) невозможен | С |
| T12 | Счёт в образе коэрции; вывод "picked up and mastered three books ⊨ three physical ∧ three informational" **без аксиомы инъективности** | С |
| T13 | Машинно проверенный контрпример к `Three Book ⇒ Three Info` без аксиомы (конечная модель) | Л |
| T14 | `A/~_c ≃ Im(c)`; `P ∘ c` пропускается через фактор | Л |
| T15 | Инвариантность относительно перекодирования онтологии (принцип тождества структур, univalence) | С |
| T16 | Корректность проверяющего: `check c ≡ true → Valid c` | С |
| T17 | Аудит лексикона: объявленные 2-клетки корректны в каноническом конечном модели KB | Л |
| T18 | Сертификат различимости классов (конструктивная аппартность) корректен | С |

Теоремы параметризуются границей длины маршрута `k` (в пайплайне `k <= 2`); незаполненные циклы либо заполняются 2-клетками, либо запрещаются лексиконом.

## 4. Пайплайн на одном предложении

Пример: *"Brussels rejected the proposal."* (место вместо институции).

```
 текст + цель
   | 1  локальная структура (UD-разбор -> GF-подобный терм окна)         [нейро + правила]
   | 2  типизация слов, ожидаемые типы слотов                            [лексикон + LM]
   | 3  типовой конфликт -> дыра для коэрции                             [Haskell]
   | 4  кандидаты: пути в K(ctx) от буквального к ожидаемому типу        [KB + шаблоны + нейро-фильтр]
   | 5  скоринг кандидатов контекстом                                    [нейро]
   | 6  классы маршрутов и структура неоднозначности                     [Haskell]
   | 7  режим: Resolve / Retain / Conjoin / воздержание                  [Haskell + пороги]
   | 8  сертификат                                                       [Haskell]
   | 9  проверка сертификата                                             [Cubical Agda]
   v
 метка + интерпретация + объяснение + статус проверки
```

Метка для бенчмарка: метонимия ⇔ выбранная коэрция не тождественна. Сертификат содержит терм, типы, дыру, маршрут с ID рёбер, использованные эквивалентности, режим, референт с ID фактов; для неоднозначности также классы, свидетели различимости и свидетельство полноты относительно лексикона. Скоры в сертификат входят как метаданные и не проверяются.

**Чего проверка не гарантирует:** истинность рёбер и фактов KB, корректность скорера, соответствие суждениям людей.

Технические границы: Python для нейро-шагов (1, 2, 5, entity linking); Haskell для ядра (3, 4, 6, 7, 8; GF как библиотека PGF); Agda как проверяющий; обмен через JSON.

| Набор | Что оценивает | Доступность |

| SemEval-2010 Task 7 | Аргумент + коэрция, тип источника и цели | asc-task.org (проверить доступность) |
| Собственный набор, 150-300 примеров | Замороженные метонимии, зависимость от субъекта, намеренная неоднозначность, зевгма, минимальные пары | Создаётся; два аннотатора, каппа |

**Режимы:** R0 (zero-shot, основной), R1 (k = 5, 10, 50 примеров), R2 (полное дообучение, верхняя граница).

**Абляции:** A независимый argmax; B склейка маршрутов (усечение); C согласованность вдоль циклов.

**Гипотезы (могут не подтвердиться):**
- H1: типовое ограничение кандидатов повышает точность типа коэрции.
- H2: кросс-категорийная и кросс-датасетная устойчивость лучше, чем у BERT.
- H3: вывод в виде множества чтений улучшает калибровку и работает на классе mixed.
- H4: инвариантность к перекодированию онтологии и перефразированию.

**Протокол:** фиксированные разбиения; пороги подбирать на отдельной выборке; несколько запусков; бутстрап-интервалы, McNemar; метрики accuracy, macro-F1, F1 метонимического класса, ECE, кривая риск-покрытие, доля сертификатов, принятых проверяющим.

## 7. Контрольные точки

1. **После проверки литературных пунктов выше:** если найдена механизированная работа с тем же ядром, сужаем вклад до системы и режимов.
2. **После E2:** вариант 2 не должен заметно уступать варианту 1 в R0. Порог (не хуже чем на N пунктов) выбрать **заранее**, вместе.
3. **После F2 (M1):** если T6 и T12 в кубической Agda оказываются тривиальными, усиливаем систему и M2.

## 8. Риски

1. Новизна уже занята (сужаем вклад).
2. Покрытие лексикона и графа смыслов (нейро предлагает рёбра локально, символика композирует).
3. Ошибки разбора; контаминация LLM-базлайнов (ConMeC и ReLocaR из Википедии).
4. Расхождение критерия «коэрция не тождественна» с разметкой ConMeC (судят по смене категории).
5. Разрешимость ≈ (T7) требует подходящей системы 2-клеток.
6. Ядро в кубической Agda: совместимость с компиляцией.
